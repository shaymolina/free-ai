# תוכן עמוד הסקילים

## בדיקת אבטחה לאתר ולאפליקציה
- **קטגוריה:** אבטחה
- **מה הוא עושה:** בודק 34 פרצות אבטחה באתר או באפליקציה שבנית עם AI (Lovable, Bolt, Base44, Claude Code ועוד) ונותן דוח אדום / כתום / ירוק בעברית פשוטה.
- **דוגמה:** כותבים ל-Claude "תבדוק לי את האבטחה של האתר" ← מקבלים רשימה של כל החורים ומה לתקן קודם.
- **מקור:** https://github.com/openforge-lab/website-security

## בדיקת מהירות לאתר
- **קטגוריה:** ביצועים
- **מה הוא עושה:** בודק 69 דברים שמאטים את האתר, כולל מיקום השרת מול הגולשים בישראל, ומדרג תיקונים לפי כמה שניות כל אחד חוסך – עם פרומפט מוכן לכל תיקון.
- **דוגמה:** כותבים ל-Claude "האתר שלי איטי, תבדוק" ← מקבלים דוח עם מה לתקן קודם ופרומפט להדבקה בכלי שבנה את האתר.
- **מקור:** https://github.com/openforge-lab/site-speed
