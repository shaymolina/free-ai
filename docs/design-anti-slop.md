# חוקי עיצוב נגד AI Slop (חובה לכל עמוד, רכיב, איור ותמונת שער באתר)

העיקרון מעל הכול: אסור בתכלית האיסור לייצר אתר שנראה כמו תוצאה גנרית של כלי AI לבניית אתרים. ברירת המחדל היא עיצוב נקי, מדויק, קלאסי ומאופק, עם צבעוניות מצומצמת, טיפוגרפיה מוקפדת, רכיבים שימושיים וצילומי מוצר אמיתיים.

4. אסור להוסיף הילות זוהרות מאחורי כרטיסים, כפתורים או כותרות.

6. אסור להשתמש בצבעי ניאון ללא הצדקה מיתוגית.
7. אסור להוסיף רקע עם נקודות, כוכבים או חלקיקים רק כדי למלא שטח.
