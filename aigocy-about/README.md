# Aigocy section library

- `sections.html` – catalog of all 39 unique sections with previews.
- `sections/` – one standalone HTML file per section (`sections.json` lists them with source page and classes).
- `*.html` in this folder – the 12 full source pages.
- `assets/` – shared styles, scripts, fonts and images.

Sections 01–18 come from the home page; the rest are sections from other pages that do not exist on the home page.
